# Login Slideshow Images

This directory contains the 4 background images used in the `/login` left brand panel slideshow:

1. **`slide-1.jpg`** - Family at home (life and family protection)
2. **`slide-2.jpg`** - Health and wellbeing (health insurance support)
3. **`slide-3.jpg`** - Home and property (property & casualty protection)
4. **`slide-4.jpg`** - Travel or vehicle (auto and mobility coverage)

### Recommended Image Specs

- **Aspect Ratio**: 16:9 or 3:2 vertical/landscape (displayed with `object-fit: cover`)
- **Resolution**: 1920x1080px or higher
- **Format**: JPG or WebP optimized for web delivery
